Projet Chiaki : Quest of liberty
les déplacements : 
- ZQSD = se déplacer (clavier)
- Espace = se propulser (clavier)
- joystick Gauche = se déplacer (manette)
- Gachette droite = se propulser (manette) 

vous serez lancés dans le niveau avec uniquement la possibilité de vous déplacer. 
Continuez à avancer pour débloquer la propulsion en avant. 
Passez à travers le premier Torii pour découvrir qu'ils vous propulsent.
Vous arriverez dans une zone dans laquelle se trouvent 3 clés, récuperez-les pour déverouiller la porte.
Passez à travers et vous arriverez dans une grande zone en ligne droite avec des collectibles en face de vous, 
Avancez et tentez de tous les récupérer en esquivant le rocher au mileu de votre trajectoire pour descendre et accéder aux Toriis et ainsi finir le niveau.
